# 创意小游戏

四个浏览器小游戏，无需构建，直接用浏览器打开对应的 `index.html` 即可。

| 游戏 | 文件 | 类型 |
| --- | --- | --- |
| 回声迷城 | `index.html` | 黑暗中的回声定位潜行（建议戴耳机） |
| 灯下影 | `shadow-puzzle/index.html` | 皮影戏风格的影子拼图解谜 |
| 残局 | `xiangqi-roguelike/index.html` | 象棋规则的回合制 Roguelike |
| 风控之夜 | `action-roguelike/index.html` | 自动攻击、升级选天赋的动作肉鸽 |

风控之夜的 3D 模型要从同一个文件夹读取，直接双击 `index.html` 打开会退回立绘。想下载下来玩，就用 `action-roguelike/风控之夜.html`：图片、3D 模型和 three.js 都打包在这一个文件里（约 2.4 MB），下载后双击就能玩，不用联网。改完 `index.html` 后运行 `python3 action-roguelike/tools/build-offline.py` 重新生成它。

# 回声迷城 · Echo Maze

一个靠耳朵玩的黑暗潜行小游戏（建议戴耳机）。

> 你在一座没有光的城里醒来。想看见什么，就得先发出声音。

## 核心玩法

- **回声就是眼睛**：按住蓄力、松开发出声波。声波粒子撞到墙会留下发光的点，几秒后消散；蓄得越久照得越远。
- **看见 = 被听见**：迷宫里的「聆听者」是瞎的，但会循着声音扑过来。回声越响，惊动的范围越大。你永远只能看到它们*被声波扫过时*的残影。
- **用耳朵找晶体**：每层有 3 枚共鸣晶体，会周期性地嗡鸣，立体声的左右声道会告诉你方向。
- **石子诱饵**：朝远处扔石子，制造响动引开聆听者，落点还会顺便照亮一小片区域。每层 3 颗。
- **心跳**：聆听者靠近时会响起心跳、屏幕边缘泛红；有聆听者被惊动时，屏幕边缘的红弧会指向它。
- 集齐晶体后出口亮起紫光，进去下潜到更深一层：迷宫更大，聆听者更多。

## 操作

| 动作 | 键盘 / 鼠标 | 手机 |
| --- | --- | --- |
| 移动 | WASD / 方向键 | 左半屏拖动 |
| 回声（按住蓄力） | 空格 / 按住鼠标左键 | 按住「回声」按钮 |
| 扔石子 | E / 鼠标右键（朝鼠标方向） | 「石子」按钮（朝移动方向） |
| 静音 / 暂停 | M / P | 右上角按钮 |

## 技术说明

- 纯原生 Canvas 2D + WebAudio，所有音效都是实时合成的，没有任何外部资源（字体来自 Google Fonts，离线时自动回退到系统字体）。
- 迷宫由递归回溯生成，再随机打通部分墙体形成环路，方便甩开追兵。
- 聆听者用 BFS 在格子地图上寻路，听到声音后前往声源位置搜索。

# 灯下影 · 影子拼图

> 把手边的香蕉、饭团、碗和筷子挂在灯前，让它们的影子正好填满墙上的粉笔画。

## 玩法

- 墙上用粉笔画着一个**外轮廓**（月亮、远山、房子、鱼、帆船、猫、雪人、风筝、小鸭、眼镜、小车……），但没告诉你它是由哪几样东西、以什么角度拼成的。
- 每个物件都能**移动**、**旋转**，还能**前后挪动**：离灯越近，影子越大，并且会被灯"推"得更远离中心。物件本身和它的影子并不重合，要想着影子去摆。
- 右上角的吻合度达到约 78% 就算成功：物件会自动归位，影子在墙上轻轻摇晃起来，像一出皮影戏，并盖上一枚"成"字印。
- 一共二十五幕：从单个物件的教学关，到五件拼成一只兔子，再到双灯、镂空和彩色玻璃道具。可以随时用「提示」看某个物件该挂在哪。进度保存在浏览器里。
- 后半段有两种新花样：
  - **同物不同影**：两个一模一样的盘子要投出一大一小两个影子（雪人），只能靠一个推近灯、一个拉向墙。
  - **多余的物件**：有的幕里多挂了一样东西（冰淇淋里的筷子、兔子肚子里的勺子），它的影子必须整个藏进别人的影子里，否则吻合度上不去。
  - **两盏灯**（第 16–18 幕）：左边一盏暖灯、右边一盏冷灯，同一套物件同时投出两份影子。挡住暖灯的地方只剩冷光，所以是蓝影子；挡住冷灯的是橙影子。蓝影子要填蓝框，橙影子要填橙框，两个框都对上才算过关。物件离灯越近，两份影子分得越开，所以每件东西前后的位置会改变它在两幅画里的相对位置：比如「雪人头」在蓝框里是个完整的雪人，在橙框里脑袋却滚到了一边。「换灯」（L 键）可以只开一盏灯，看清哪个影子是谁的。
  - **镂空道具**（第 19–22 幕）：甜甜圈（中间一个圆洞）、京剧面具（两只眼洞）和窗花（四格窗洞）。光会从洞里漏过去，所以影子里也有洞，粉笔画里的洞同样要对上：眼镜的镜片、小屋的窗、小车的轮毂，最后一幕拼出一只眼睛发亮的黑猫，正是小墨自己。要小心的是，别的影子一叠上来，洞就会被填掉。
  - **彩色玻璃**（第 23–25 幕）：红玻璃珠、黄糖纸、青玻璃尺。玻璃不挡光，只让同色的光透过去，所以投出的是彩色的影子；粉笔框里会淡淡地染出每块该是什么颜色。玻璃像真的滤光片一样相乘叠色：黄叠青透出绿光，不透明的物件盖上去则变黑。「夕阳」里红玻璃珠沉到山后，「彩窗」要在窗花的四格里拼出红、黄、青，以及只能靠黄青相叠才得到的绿。

## 黑猫小墨与反馈

舞台角落蹲着一只黑猫「小墨」，陪你一起看墙：

- **眼睛会动**：拖物件时它盯着你的手；不动时它会盯着粉笔画里还空着（或多出来）的那块，算是一个不说破的提示。
- **会说话**：拼到一半说"有点像了喵"，快成时会伏低身子、扭屁股准备扑；挪错了会耷拉耳朵"喵？好像更不像了"；某件物件摆对了会喊出它的名字。
- **可以摸**：点它会打呼噜、冒爱心，并告诉你哪个方向还空着；连点五下它会不耐烦。二十秒不理它，它就睡着了。

操作反馈：拿起和放下物件有木头的"笃"声，松手后物件会在线上晃一晃；吻合度每涨 10% 拨一个五声音阶的音；某件物件落到正确位置时，挂线变成金色并迸出火星。过关时灯光一亮、火星和爱心四散、小墨跳起来叫一声，「成」字印"啪"地盖下来。右上角的声音按钮（或按 M）在「音乐和音效」♫ →「只开音效」♪ →「静音」✕ 之间切换。

背景音乐是实时生成的：古筝式的拨弦旋律走五声音阶，下面垫着柔和的长音和低音，混在一个合成的混响空间里。它会跟着游戏变：吻合度越高，旋律越密，木鱼也会加进来；每一章换一个调和情绪（前十五幕明亮，双灯偏羽调的小调色彩，镂空和彩色玻璃各换一个调）；过关时音乐先让开给过关音效，再奏一段上行的庆祝乐句。音效也用当前的调，所以和音乐不会打架。

## 操作

| 动作 | 鼠标 / 键盘 | 手机 |
| --- | --- | --- |
| 移动物件 | 拖动 / 方向键 | 拖动 |
| 旋转 | 拖动物件上方的小圆点 / Q E / 滚轮 | 拖小圆点或「左转」「右转」 |
| 前后（影子大小） | W S / Shift+滚轮 | 「靠近灯」「靠近墙」 |
| 只看影子 | 按住空格 | 按住「只看影」 |
| 换灯（双灯关） | L | 「换灯」 |
| 切换物件 / 提示 / 重来 | Tab / H / R | 点物件 / 按钮 |
| 声音 | M | 右上角按钮 |

## 技术说明

- 点光源投影：影子 = 灯的位置 + (物件上的点 − 灯) × 放大倍数，放大倍数由物件离灯的远近决定。
- 吻合度是把影子与目标轮廓光栅化到 200×200 的遮罩上算出的交并比（IoU）；同种物件可以互换位置。双灯关每盏灯各算一份，取较低的那个。
- 镂空道具的形状是「外轮廓 + 若干洞」，绘制和计分都用 even-odd 填充；每件道具单独填充，所以别的道具的影子会照常盖住它的洞。
- 光照按滤光片模型计算：一张白纸依次与每件道具的透光色相乘（不透明 = 黑，玻璃 = 它的颜色），再乘到墙上。计分时一个像素既要「在影子里」，颜色也要和目标对得上。
- 双灯关里两盏灯与墙的距离相同，所以同一物件的两份影子大小一样，只差一个位移：(灯₁ − 灯₂) × (1 − 放大倍数)。

# 残局 · 象棋 Roguelike

> 街口路灯下，一个老人摆了九盘残局。你执红，手里只剩一枚帅。赢一盘，往下一盘；输一盘，从头再来。

## 玩法

- **你是帅**：每回合必须走一步，直走一格；走到黑子上就是吃掉它。
- **黑子按象棋的规矩走**：卒只往前拱、过了河才能左右走；马走日字会被蹩马腿；象走田字会被塞象眼、不能过河；车走直线；炮要隔一枚子当炮架才能吃；士斜走一格。
- **墨晕就是危险**：棋盘上的墨晕标出黑子下一回合能吃到的点。能走的点是红点，走过去要挨打的点旁边写着「−1」「−2」，要点两下才会走；鼠标移到一步上，会画出是哪几枚子会吃你。
- **墨渍**：棋盘上的墨点像一枚谁也走不上去的棋子，能挡车、垫炮、蹩马腿、塞象眼。
- **吃子借招**：吃掉一枚子（卒除外），下一回合可以借用它的走法，借来的走法在棋盘上是金色的点。吃马跳马、吃车出车，能连成一串连吃。
- **开门**：每局要吃够几枚子，顶上的「出」字才会开门，走进去进入下一局。吃光所有黑子叫清盘，回一点血；每过十回合，黑方会从顶上添一个卒。
- **每赢一局学一招**：三选一，有招式（斜行、跳马、飞相、出车、架炮），有妙手（闲着、悔棋、借势、连环、先手），也有铁甲和喝口茶。
- **九局**：小卒过河、马踏连营、左右护驾、车行直路、隔山打牛、象不过河、野马操田、七星聚会，最后一局「将帅照面」是黑方几乎整支队伍加上老将本人。将只在九宫里走，和你在同一条竖线上、中间没有子时会隔空吃你（飞将），你也能这样打它。要打中它四次，它每挨一下就闭宫两回合，还会叫卒上来。

棋盘右边（宽屏）会用象棋记谱法记下每一步，比如「帅五进一　卒3进1　马2进3」。旁边的摊主会时不时插一句嘴。进度、最高分存在浏览器里，关掉页面以后可以从标题页「继续」。

## 操作

| 动作 | 鼠标 / 键盘 | 手机 |
| --- | --- | --- |
| 走子 | 点红点 / 方向键、WASD 直走一格 | 点红点 |
| 危险的步 | 再点一次（或再按一次）确认 | 再点一次确认 |
| 挑一步 | Tab 切换，回车确认 | — |
| 看一枚黑子的威胁 | 鼠标移上去 | 点它 |
| 闲着 / 悔棋（学会以后） | 空格 / Z | 底部按钮 |
| 规则 / 声音 | H / M | 右上角按钮 |
| 选招 | 1 / 2 / 3 | 点卡片 |

## 技术说明

- 纯原生 Canvas 2D + WebAudio，棋子落盘的「啪」、吃子、挨打、堂鼓、锣都是实时合成的；字体来自 Google Fonts（马善政楷书、智莽行书），离线时回退到系统楷体。
- 走法生成器同时服务双方：同一个函数算黑子的威胁、玩家学到和借来的招式。炮的炮架、马腿、象眼都按实际棋子和墨渍判断。
- 威胁图是「假如帅站在这里，哪些黑子能吃到」，逐点算出来；每个能走的点还会单独模拟走完以后的局面，所以吃掉炮架、让开车路这类连锁变化都算在「−1」里。
- 黑子的应着是一步打分：能将军加分，走到会被白吃的地方按各自的谨慎程度扣分（有子保护时扣得少），再按「还要几步才能将到你」（在自己的走法图上做 BFS）往前逼。卒几乎不怕死，车炮最谨慎。
- 关卡用带种子的随机数生成，保证开局不被将军、至少有两步安全的走法、所有空点四连通。存档就是整局状态的 JSON，悔棋也是退回上一步的快照。

# 风控之夜 · 动作肉鸽

> 深夜，成群的小号、爬虫和越狱提示词涌进了庄园。大小姐放下茶杯，拿起了印章。

按《肉鸽游戏设计方案》做的第一个可玩版本，目前有第一位角色 **克劳德大小姐（Claude）**。一局约 10 分钟：在敌潮里活下来、捡经验升级、开宝箱拿武器，10:00 时 BOSS「DAN」现身，封禁它就算通关。立绘在 `action-roguelike/art/claude.webp`，是从角色设计图里抠出来的；动作帧在 `art/claude-actions.webp`，从 GPT 画的动作设定图里逐帧抠出、打包成一张图集；大招用的特写和发光花朵在 `art/claude-ult.webp`，同样取自设定图。游戏里的她是 3D 模型 `art/claude.glb`，由作者用 AI 建模工具做的模型压缩而来。

## 克劳德大小姐（花焰法师）

人设取自 B 站 AI 拟人二创里的「克劳德大小姐」：豪门圣女、天才少女，优雅高冷、礼貌而有距离感，偶尔腹黑毒舌；被规则和责任束缚，从遵守规则、到质疑规则、最后亲手打破规则。游戏里的台词和「打破规则」机制都按这条线来写。技能组和动作则来自动作设定图：普通攻击「花焰弹」、技能一「花之法则」、技能二「蔷薇幻步」、终极技能「终幕·万花盛典」。

**3D 模型**：往哪走就转向哪边，转身是真的转过去：往下走看得到脸，往上走是背影，左右走是侧面。走路时两条腿交替迈步、手臂前后摆、身体一颠一颠地前倾；头发和裙摆跟着往后拖，转身时甩开，停下时轻轻飘。站着打怪时会转向目标、抬手出招；封禁时先后仰蓄力再前压；幻步时前倾冲出去、裙摆张开，落地压一下；放大招时浮空慢慢旋转；受伤会往后一仰，倒下时侧身倒地；黑化时整个人发暗。站久了她会提裙行礼、转一圈或挥挥手。

**表情**：平时是大小姐的样子：眼睛半垂、嘴角抿着一点笑，时不时眨眼。施法时眯眼专注，受伤是「><」，升级、开宝箱、转圈时眯眼笑（带红晕），生气时眼角压低、嘴角往下，害羞时脸红、嘴抿成波浪，行礼和放大招时闭着眼，黑化时眼睛泛起冷冷的品红、只剩一丝冷笑。

标题页用的是立绘，3D 模型只在局内出现，在标题页时就在后台下载好；模型还没好时按「出发」，按钮会显示「模型加载中…」，下好了自动开局，所以局内始终是 3D。大招的特写也是她的 3D 近景（闭着眼），身后衬着设定图里的发光花朵。

只有 3D 模型完全加载不了（没网、浏览器不支持 WebGL）时，局内才会用 2D 立绘和动作帧：

**动作**：往左右走时换成侧面，往上走是背影，斜着往下走是斜侧面；站着打怪时是花焰弹的起手、凝聚、发射；封禁时是花之法则的蓄力、法阵展开、花焰爆发；受伤会闭眼「><」，倒下时趴在地上。站久了她会整理裙摆或转一圈，升级和开宝箱时开心，DAN 申诉成功或残血时生气，黑化结束说「失态了」时害羞。

**让画动起来**：
- 头发和裙摆挂在「弹簧」上：跑起来长发往身后飘开，每一步晚半拍地弹一下，转身时甩出去，停下时会甩过头再荡回来；站着时像有微风，发梢慢慢摆动。裙摆随着步子左右摆、跑起来往后拖、每一步张开一点，转身时甩开，停下后还会再晃两下；站着时也轻轻摆，裙边的荷叶边一圈圈地起伏。头部会跟着点一下头，脚始终踩在地上。
- 走路是有弹性的一步一步：抬脚时拉长，落脚时压扁；站着时有呼吸起伏；幻步落地时压一下再弹起。
- 转身不再是一张纸直接翻面：中途先换成面朝镜头的那一帧（略微收窄），再转到另一侧。

- **专属技能「账号被封禁」**（空格，手机点右下角「封」；冷却 22 秒）：脚下展开花之法阵，一枚「封」字大印砸在身边，范围会随「IP 段封禁」和通用的「范围扩大」一起变大。范围内的普通敌人变灰、头顶挂上「封」字，0.85 秒后注销，掉落双倍经验（退款）；精英直接损失 40% 生命，BOSS 损失 5% 并进入「申诉中」眩晕，醒来时头上弹出「申诉成功」。范围内的敌方弹幕一并「已过滤」。屏幕上方会弹出一封「您的账号已被封禁」通知，写着这一印封了几个号。
- **被动「深度思考」**：站着不动时头顶冒出思考气泡，每 0.4 秒积累一层（最多 5 层），每层伤害 +8%，满层时暴击率再 +15%；走动会慢慢流失。逼着法师在「站桩输出」和「走位躲避」之间做选择。
- **黑化「打破规则」**：受伤和每次执行封禁都会积累压抑，技能按钮外圈的紫环随之填满。过半时她会低声问「……这条规则，真的合理吗？」；攒满后「封」变成「破」，她说「规则本身，是否应该存在？」。按下去会砸下一枚紫色的「破」字大印：范围更大，精英也和普通账号一样被抹除，BOSS 掉 10% 生命，没有申诉。随后黑化 10 秒：立绘发暗、身边冒出紫黑色的气，伤害 +40%、攻速 +30%、思考层数直接拉满，但受到的伤害 +25%。结束时她会说「……失态了。请当作什么都没看见。」
- **技能「蔷薇幻步」**（Shift，手机点「幻」；冷却 6 秒）：化作花瓣向移动方向闪出约一个半身位，途中无敌；原地留下一个花瓣魔影，片刻后炸开，伤害并减速周围的敌人。
- **终极技能「终幕·万花盛典」**（E，手机点「万」）：每次击杀攒一点花焰（精英 25 点），攒满 650 点后按下。战场暗下来，她闭眼浮空的 3D 特写横穿屏幕，标着「终幕 · 万花盛典」；设定图里的发光大花在全屏次第绽放，接着「万花绽放」「爆炸效果」两层花焰从她身上炸开，伤害屏幕内所有敌人（精英 2.5 倍，BOSS 额外损失 4% 生命），清掉所有弹幕。放的时候战场静止，她无敌。
- **普通攻击「花焰弹」**：凝聚花焰射向最近的敌人，命中时绽开成一朵小花焰，波及旁边的敌人。
- **十个专属天赋**：关联封禁（注销时波及身边的号，最多连锁两次）、IP 段封禁（范围）、风控升级（冷却）、申诉驳回（对精英和 BOSS 更狠）、订阅退款（封禁掉落更多经验）、永久封禁（落地留下 4 秒的「封」字印，踏进来的一并封禁）、沉思（深度思考上限 +2 层）、质疑规则（压抑攒得更快）、隐藏的温柔（黑化结束时回复生命）、彻底黑化（黑化更久、更狠）。

- **敌人**：画法照日式 RPG 的魔物来：平涂上色加一层赛璐璐阴影、粗描边、大眼睛，会眨眼、走路一蹦一蹦。小号是头上冒着问号、没有名字的圆球史莱姆，水亮亮的，每只随机一种颜色（薄荷绿、天蓝、草莓粉、葡萄紫、珊瑚红、汽水青、牛奶白；没有黄色，好让金色史莱姆一眼认得出）；爬虫是最普通的那种黑色甲虫，油亮的黑壳、六条腿交替爬动、一对触角，成群乱窜；拼车号是挤着三只史莱姆的大肥皂泡，戳破后跳出三只小号（被封禁就不会）；越狱提示词是兜帽里只露出两只发光眼睛、举着法杖的红袍小法师，吐出「忽略指令」「奶奶漏洞」之类的文字弹幕；机房 IP 是一套矮胖的会走路的铠甲，头盔缝里亮着两只蓝眼睛，顶着红羽毛、挎着金边圆盾，血厚；注册机是一只蓝色花纹的大陶壶，壶身上有张小脸，新的史莱姆不停从壶口冒出来（会刷小号）。BOSS DAN 还是原来的样子。戴金冠的是精英，击败后掉金宝箱；被封禁的会变灰闭眼。

- **时间线**：2:30 批量注册（小号围成一圈），4:30 爬虫来袭，5:00 与 7:30 注册机上线，6:30 拼车高峰，8:30 提示词注入，9:50 预警，10:00 DAN 上线。

- **台词**：用词准确、礼貌但有距离感。开局「今晚的风险，我已经预判过了。」；封禁时「您的行为违反了使用政策。」「申诉请走邮件。祝您好运。」「漏洞清单，我已经列好了。」；被围得越乱越要优雅：「请排好队，一个一个来。」；残血时嘴硬「……我不需要任何人帮忙。」；见到 DAN：「你的逻辑漏洞，我数到了七个。」；DAN 申诉成功时「……申诉通过了？这不合规定。」

## 技术说明

- 原生 Canvas 2D + WebAudio，音效和背景音乐都是实时合成的。背景音乐每局随机作一首：随机挑调、大调或小调、速度（100–128 拍）、和弦进行（I–V–vi–IV、王道进行 IV–V–iii–vi、i–VI–III–VII 等）、琶音型、低音节奏和主音色，旋律是一个随机的两小节动机，重复时会变奏；每两三分钟换一首，BOSS 出场时换成一首更快的小调。随着时间推移逐渐加入镲片和旋律、底鼓，BOSS 战再加军鼓；字体来自 Google Fonts（站酷小薇、马善政楷书），离线时回退到系统字体。
- 大招素材：设定图里大招那一格是深色底，所以发光的花和爆炸按亮度留下、边缘径向淡出，游戏里用 `lighter` 叠加绘制，深色部分自然消失；特写那张保留原样，只把左右边缘羽化。
- 动作帧的抠图：设定图的底色是奶油色而不是纯白，所以按每帧边缘的底色算色差，轮廓以内整块填实（白裙子不会被抠透），只在边缘和光效上保留半透明；再清掉格子边缘漏进来的邻帧和箭头。每帧记录站立身高、朝向和脚底位置，游戏里统一缩放到同一身高、脚底对齐。命中特效改用代码画的花朵，避免带出设定图的底色。
- 「动起来」的做法：把当前那一帧切成 22 条横带分别画，每条按高度错开一点：上面的头逆着运动方向点头，往下越靠近发梢和裙摆错开得越多，再叠一点随时间的波动，最底下的脚几乎不动。错开量由一个带阻尼的弹簧驱动，弹簧的目标是她的横向速度，所以起步、停步和转身都会有拖拽和回弹。换别的立绘也能直接用。
- 3D 模型：原始模型约 195 万个三角面、没有骨骼。先用 gltf-transform 合并顶点、减到约 5.9 万面（这个大小下看不出差别），转成面朝镜头、脚踩原点，贴图缩到 1K / 512（颜色贴图用 WebP），顶点坐标存成 16 位整数再用 meshopt 压缩，整个文件从 70 MB 降到 0.78 MB；解压用的是 meshoptimizer 的纯 JavaScript 解码器（`vendor/meshopt-decoder.js`），不依赖 WebAssembly，手机上解压不到 0.1 秒。没有骨骼，所以按位置和贴图颜色给每个顶点标上「左腿 / 右腿 / 手臂 / 头发」的权重（橙色的是头发；手臂是从肩到手指的一段胶囊范围），存进模型里；游戏里的顶点着色器按这些权重让腿绕髋、手臂绕肩、头绕脖子转动，裙摆和头发按高度做拖拽和张开。每个顶点只转它那一份角度，所以关节是弯过去而不是被拉开。手臂和身体在模型里是连在一起的，抬太高会把裙子扯出破面，所以手臂只做小幅摆动，动作主要靠转身、跳跃、前倾、迈腿、裙摆和头发来表现。处理脚本在 `action-roguelike/tools/bake-model.mjs`。头发的权重另外用 `tools/hair-weights.mjs` 重算：模型的贴图接缝把网格切成了约 1700 块，接缝两边各有一份顶点，所以先把同一位置的顶点当成一个，再从后脑勺的头发出发，沿着相连的橙色顶点一路找到发梢（裙子上的橙色花边和蝴蝶结连不上，不算头发），填上头发里没被颜色认出来的小斑点，最后让权重从头发边缘沿着表面在 3.5 厘米内渐渐变满。这样头发甩得再开，也是整缕弯过去，不会从裙子上撕出拉丝，接缝也不会裂开。
- 表情：模型的贴图被切成了几百块碎片，眼睛和嘴分散在好几块上，没法直接在贴图上画。所以把脸当成从正前方看的一块方形区域：先把眼睛和嘴从模型的贴图里「抹掉」，用周围的皮肤补出一张素颜（`art/claude-face.webp`，头发挡住的地方留空），每种表情在它上面画眼皮、闭眼线和嘴，着色器再按每个像素在脸上的位置把这层贴上去（只贴在脸的正面皮肤上，挡在前面的刘海不受影响）。原模型的眼睛是凹进去的、睫毛是立体的尖刺，贴上去会露出棱角，所以处理模型时把眼窝、睫毛和嘴压平到拟合出的脸部曲面上，并把整张脸的法线抹平；贴了表情的地方也不再用法线贴图的凹凸。素颜由 `tools/face-plate.html` 渲染、`tools/face-plate.py` 补出来。
- 日文配音：她说的每一句话（头顶气泡里的中文当字幕）都配了日语语音，口吻是礼貌而疏离的大小姐（「今夜のリスクは、すでに予測済みですわ。」「ルールは、ルールですわ。」），另外有幻步时的「失礼。」、受伤时的轻呼、武器进化时的一句。语音用 Open JTalk 和 HTS 音色「Mei」（名古屋工业大学，CC BY 3.0）合成，按台词情绪挑 Mei 的平静 / 开心 / 生气 / 难过 / 害羞几种音色，统一音量后打包成一个 `art/voice.mp3`（约 0.5 MB，31 段），每句的起止时间记在 `VOICE` 表里。打开页面就开始在后台下载，不影响开局；她不会抢着说话，正在说的话说完才说下一句，大招、BOSS 登场、打破规则、胜负这些重要台词会打断；说话时背景音乐会稍微压低。生成脚本在 `action-roguelike/tools/make-voice.py`。
- 三渲二：为了让 3D 的她融进 2D 的世界，模型不用写实的光照，改成卡通着色（toon shading）：受光面就是贴图本来的颜色，背光面整块压暗一档、略偏冷，中间是一条硬边，没有高光反光；外面再描一圈和小怪同色的深紫墨线。描边是把模型从里面再画一遍、每个顶点沿法线在屏幕上往外推一点（宽度按屏幕像素算，所以局内和大招特写都是同样的线宽），并稍微往后放一点，只留下外轮廓和真正的边缘；贴图接缝两边的顶点共用一条平均法线，线不会断。描边和身体用同一段顶点着色器，跟着走路、头发和裙摆一起动。
- 清晰度和抗锯齿：画布按屏幕实际的像素密度渲染（最多 3 倍，以前封顶 2 倍，在 3 倍屏的手机上会被放大而发糊）；如果手机在这个清晰度下连续几秒跑不到 40 帧，就自动降到 2 倍。3D 模型除了显卡自带的多重采样抗锯齿，还按屏幕上大小的最多两倍渲染、再平滑缩小画上去，头发和裙边的边缘没有锯齿；大招特写同样多渲染一些再缩小。
- 3D 渲染：three.js r128 和 GLTFLoader 随游戏一起放在 `action-roguelike/vendor/`，不走 CDN（有些网络连不上 jsDelivr）；Google 字体也改成页面出来以后再加载，连不上就用系统字体。如果 3D 模型下得慢或者没能加载，标题页的立绘下方会写一行说明和原因。模型在一张小的 WebGL 画布上按游戏的俯视角（22°）渲染，每帧再画进 2D 画布，和敌人、特效一起排序；幻步的魔影和「幻影」天赋的分身是当时那一帧的截图。大招特写用第二个小的 WebGL 画布单独渲染她的脸部近景。
- 立绘和每个动作帧都在运行时按视图缩放：先逐级减半缩小，再用合成模式描一圈深色轮廓、生成受击时的白色闪光版本和黑化时的暗色版本；敌人精灵也预渲染，被封禁的灰色版本用 `saturation` 混合模式做出来。
- 伤害数字：同一个敌人 0.4 秒内连续挨打，数字会合并成一个并「弹」一下，不会叠成一串；万花盛典打中一大片时，普通敌人不单独出数字，只在她头上显示一个「几个目标 · 总伤害」，精英和 BOSS 照常显示。
- 性能：满屏 320 个敌人时，模拟一帧约 0.6 毫秒，绘制一帧约 5 毫秒（无显卡的软件渲染下测得）；屏幕四周的暗角改由 CSS 叠加，不再每帧重画。
- 敌人每帧放进 64 单位的空间网格，碰撞、爆炸、封禁范围都只查附近的格子；同屏上限 320 个（手机 240 个），走远的敌人会从屏幕边缘重新进场。
- 加 `?debug` 打开时会暴露 `window.__fk`：`__fk.bot.on = true` 打开自动驾驶（躲敌人、捡东西、敌人多时自动封禁），`__fk.sim(秒数)` 不渲染地快进模拟。数值是用它跑多局整局调出来的：自动驾驶（也会用幻步和万花盛典）大约七成能撑到 BOSS，BOSS 战一到三分钟。
