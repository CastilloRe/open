# 风控之夜 · 配音台本

每句录成一个单独的音频文件，**文件名用台词编号**（`01`、`02`……，格式随意：m4a、wav、mp3 都行），两个角色分两个文件夹（`claude`、`whale`）。句子前后留点空白没关系，音量也不用统一，打包时会自动裁掉空白、统一音量。日语台词是建议，按角色语气改写也可以，只要意思对得上中文字幕就行；大肥鱼也可以直接用中文配。

录好后打包成 zip 发过来，或者一个个发也行。
