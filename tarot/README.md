# 星夜塔罗

一个单文件的塔罗占卜网页，不用构建、不用联网：用浏览器打开 `tarot/index.html` 就能用，下载下来双击也行。

## 怎么玩

1. 写下问题（可以不写），选一个牌阵，决定要不要包含逆位牌。
2. 点「洗牌」。洗好后，78 张牌背面朝上摊开，凭直觉一张张点；也可以点「替我随机抽」。
3. 牌按牌阵摆好，点一张翻一张，或者点「全部翻开」。每翻开一张，下面就出现这张牌在这个位置上的解读；全部翻开后有一段「整体来看」。
4. 「复制结果」会把整次占卜复制成纯文本。最近 30 次占卜存在浏览器本地，回到首页可以重新打开。

## 牌阵

| 牌阵 | 张数 | 位置 |
| --- | --- | --- |
| 单张指引 | 1 | 指引 |
| 时间之流 | 3 | 过去、现在、未来 |
| 二选一 | 5 | 现状、A 的过程与结果、B 的过程与结果（两个选项可以自己命名） |
| 凯尔特十字 | 10 | 现状、阻碍（横放）、根基、过去、目标、近未来、自我、环境、希望与恐惧、结果 |

## 牌与解读

- 完整的 78 张：22 张大阿卡纳，加上权杖、圣杯、宝剑、星币四组小阿卡纳，每组 14 张。
- 每张牌都有正位和逆位的关键词。大阿卡纳另有一句正位、一句逆位的寓意，还标了对应的星体或星座。小阿卡纳的解读由数字或宫廷身份的含义、花色的主题和关键词组合而成。
- 「整体来看」会看这几件事：大阿卡纳占多少、哪种元素最多或缺了哪种、逆位多不多、宫廷牌多不多、有没有重复出现的数字，以及最后一张牌（二选一则比较两条路）。
- 牌面和牌背都是用 SVG 画的，没有图片文件。洗牌用的是 `crypto.getRandomValues`。
