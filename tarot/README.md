# 星夜塔罗

一个单文件的塔罗占卜网页，不用构建：用浏览器打开 `tarot/index.html` 就能用，下载下来双击也行。联网时会从 Google Fonts 加载 Cinzel 和思源宋体，没网就退回系统自带的衬线字体，其余功能不受影响。

## 怎么玩

1. 写下问题（可以不写），选一个牌阵，决定要不要包含逆位牌。
2. 点「洗牌」。洗好后，78 张牌背面朝上摊开，凭直觉一张张点；也可以点「替我随机抽」。
3. 牌按牌阵摆好，点一张翻一张，或者点「全部翻开」。每翻开一张，下面就出现这张牌在这个位置上的解读；全部翻开后有一段「整体来看」。
4. 「复制结果」会把整次占卜复制成纯文本。最近 30 次占卜存在浏览器本地，回到首页可以重新打开。

## 牌阵

| 牌阵 | 张数 | 位置 |
| --- | --- | --- |
| 单张指引 | 1 | 指引 |
| 时间之流 | 3 | 过去、现在、未来 |
| 二选一 | 5 | 现状、A 的过程与结果、B 的过程与结果（两个选项可以自己命名） |
| 凯尔特十字 | 10 | 现状、阻碍（横放）、根基、过去、目标、近未来、自我、环境、希望与恐惧、结果 |

## 牌与解读

- 完整的 78 张：22 张大阿卡纳，加上权杖、圣杯、宝剑、星币四组小阿卡纳，每组 14 张。
- 每张牌都有正位和逆位的关键词。大阿卡纳另有一句正位、一句逆位的寓意，还标了对应的星体或星座。小阿卡纳的解读由数字或宫廷身份的含义、花色的主题和关键词组合而成。
- 「整体来看」会看这几件事：大阿卡纳占多少、哪种元素最多或缺了哪种、逆位多不多、宫廷牌多不多、有没有重复出现的数字，以及最后一张牌（二选一则比较两条路）。
- 牌面和牌背都是用 SVG 画的黑金烫金风格，没有图片文件。洗牌用的是 `crypto.getRandomValues`。

## 效果

- 背景是缓缓上浮、明暗闪烁的星空，偶尔划过一颗流星；标题后面有一圈慢慢转动的黄道十二宫魔法阵。
- 洗牌时，牌围着魔法阵转一圈再收拢。抽牌时，78 张牌摊成扇形（屏幕窄就分成几排），鼠标移上去的那张会抬起来发光，抽走的牌会飞出去。
- 牌按顺序发到牌阵上。翻牌时有一圈金色光环和火花，牌面扫过一道镭射反光。翻到大阿卡纳时光环变成紫色，牌上方浮现「ARCANUM 编号」，之后牌身一直带着紫色光晕。
- 用鼠标时，翻开的牌会跟着指针倾斜，并有一块跟着移动的反光。
- 全部翻开后，「整体来看」上方用五个发光数字和光条，显示大阿卡纳和四种元素各有几张。
- 系统设置了「减少动态效果」时，这些动画都会关掉。
